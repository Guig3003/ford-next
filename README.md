# Estrutura de Demonstração de Colaboração — Ford Next Mobile

Este repositório organiza o projeto mobile em **4 commits temáticos e significativos**, cada um em sua pasta.

Cada pasta contém:
- Arquivos da versão mobile do projeto
- Arquivo `nao-comitar.md` com a mensagem de commit sugerida em português
- Um `README.md` descrevendo o objetivo do commit

## Pastas de Commits

1. **commit-1/** — Configuração e dependências
2. **commit-2/** — Estrutura de domínio e tipos
3. **commit-3/** — Camada de aplicação (hooks)
4. **commit-4/** — Apresentação e componentes

Abra cada pasta para ver a estrutura completa e a mensagem de commit.
